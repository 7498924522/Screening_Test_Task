⚛️ React + Vite – Screening Test Project

This project is built using React + Vite + Tailwind CSS as part of a Frontend Developer Screening Test Assignment shared via email.

The objective of this project is to convert a given Figma design into a fully responsive and functional React application using modern frontend development practices.

📌 Screening Test Details
- Assignment received via email
- Task: Convert Figma design into React UI
- Focus: UI accuracy, responsiveness, and component structure
- Evaluation: Based on frontend development skills and implementation quality
